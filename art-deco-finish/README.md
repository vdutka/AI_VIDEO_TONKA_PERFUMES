# Финальная доработка v10

Скрипты, которыми Claude Code сделал v10 из ар-деко анимации Codex (v06):

| Файл | Что делает |
|---|---|
| `score.py` | Синтез оригинальной музыки (джаз 1920-х) и звукового дизайна по таймкодам сцен |
| `track2.py` | Отслеживание камеры отдельно для каждого слоя анимации (дома, комната, стол) |
| `details.py` | Детали окружения ар-деко: окна, дымоходы, дальняя городская стена с куполом и минаретом, розы, шафран, мебель |
| `refine2.py` | Сборка кадров: 1080p, детали, золотая рамка, свечение, золотая пыль, лучи финальной карточки, зерно, музыка |

Запуск: `python track2.py v06.mp4 track2.json`, `python score.py score.wav`, затем `python refine2.py v06.mp4 score.wav v10.mp4`
(нужны кадры-референсы `ref_*.png` из исходного ролика: 1,5 с, 7 с, 14,5 с и 19 с).
